# PlayerModLoader

Windows-менеджер косметических модов для обычного **Roblox Player**. Пакеты содержат только выбранные локальные ресурсы. Менеджер показывает их перед применением, сохраняет предыдущие файлы и восстанавливает их по кнопке. DLL, EXE, скрипты, FastFlags и сетевые настройки в пакетах запрещены.

## Установка и запуск

1. Скачай `PlayerModLoader-0.1.0-Windows-x64.zip` из [Releases](https://github.com/Jemyz3653/PlayerModLoader/releases/latest) и распакуй.
2. Запусти `PlayerModLoader.exe`. Выбери **Roblox** для установки с сайта или **Bloxstrap**, если запускаешь Player через него.
3. Закрой Roblox Player. Нажми **Открыть ZIP** и выбери, например, `examples/PurpleCursor.zip`. Просмотри список и нажми **Применить**.
4. Запусти Roblox обычным способом. Чтобы убрать пак, закрой Player, нажми **Восстановить** и запусти игру снова. Можно применить один пак на каждую обнаруженную установку.

В обычной установке менеджер работает с текущей папкой версии. Обновление Roblox может заменить эти файлы. Для Bloxstrap менеджер работает с папкой `Modifications`, из которой Bloxstrap подхватывает ресурсы при запуске. Если другая программа изменит тот же файл, менеджер сохранит резервную копию и сообщит о конфликте. Сборка поддерживает установки в стандартных каталогах Roblox и Bloxstrap. Версия из Microsoft Store не поддерживается.

## Формат ZIP

Папка `content` должна быть в корне архива. Можно включить любой набор из перечисленных файлов. Отдельные игры могут использовать собственные курсоры и звуки. В такой игре результат зависит от её настроек.

| Ресурс | Путь внутри ZIP |
| --- | --- |
| Основные курсоры | `content/textures/Cursors/KeyboardMouse/ArrowCursor.png`, `ArrowFarCursor.png`, `IBeamCursor.png` в той же папке |
| Курсоры из старых игр | `content/textures/ArrowCursor.png`, `content/textures/ArrowFarCursor.png` |
| Встроенные звуки | `content/sounds/ouch.ogg`, `content/sounds/volume_slider.ogg` |

PNG может иметь размер до 128×128 и занимать до 256 КиБ. Звуки должны быть в формате Ogg Vorbis и занимать до 2 МиБ на файл. Лимит ZIP составляет 8 МиБ.

## 10 предупреждений

1. За использование модифицированного Roblox Player аккаунт могут забанить.
2. Если Roblox расценит замену локального ресурса как модификацию клиента, аккаунт могут забанить.
3. Если античит распознает установку как изменённую, аккаунт могут забанить даже при косметических изменениях.
4. При нарушении правил Roblox сторонним ПО аккаунт могут забанить временно.
5. За повторное использование модифицированного клиента аккаунт могут забанить навсегда.
6. Изучай содержимое ZIP перед применением и скачивай пакеты из источников, которым доверяешь.
7. Перед применением или восстановлением полностью закрой Roblox Player и дождись завершения обновлений.
8. После обновления Roblox проверь совместимость пака с новой версией.
9. Сохраняй резервные копии менеджера в `%LOCALAPPDATA%\PlayerModLoader` до восстановления исходных файлов.
10. Ответственность за выбор пака, его применение и использование изменённых ресурсов лежит на пользователе.

[Правила Roblox о модифицированных клиентах](https://en.help.roblox.com/hc/en-us/articles/24275616578708-Anti-cheat-Messages) · [Как Bloxstrap загружает локальные ресурсы](https://github.com/bloxstraplabs/bloxstraplabs.com/blob/main/src/content/docs/wiki/features/modding.mdx)

## Сборка

На Windows с Python 3.11+ запусти `python app.py` для запуска из исходников. Для портативного EXE установи PyInstaller и выполни `python -m PyInstaller --onefile --windowed --name PlayerModLoader app.py`. Результат появится в `dist`.

`python -m unittest -v` проверяет операции на отдельной временной установке.
