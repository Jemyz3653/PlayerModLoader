# PlayerModLoader

Windows-менеджер косметических модов для обычного **Roblox Player**. Пакеты содержат только выбранные локальные ресурсы. Доступны стандартное небо, курсоры и звуки. Менеджер показывает их перед применением, сохраняет предыдущие файлы и восстанавливает их по кнопке. DLL, EXE, скрипты, FastFlags и сетевые настройки в пакетах запрещены.

## Установка и первый мод

1. Скачай `PlayerModLoader-0.3.0-Windows-x64.zip` из [Releases](https://github.com/Jemyz3653/PlayerModLoader/releases/latest), распакуй и запусти EXE.
2. На вкладке **Библиотека и профили** нажми **Импорт ZIP** или **Импорт папки**. В архиве лежат два примера, `examples/VioletAurora.zip` и `examples/PurpleCursor.zip`.
3. Выбери мод и нажми **В очередь**. Несколько модов можно сохранить как профиль. При пересечении файлов приоритет у последнего мода в очереди.
4. На вкладке **Установка и проверка** выбери **Roblox** для версии с сайта или **Bloxstrap**. Кнопка **Проверить очередь** покажет файлы, действия и источники, включая конфликты.
5. Закрой Player и нажми **Применить**. Открой Roblox как обычно. Чтобы вернуть прежние файлы, закрой Player и нажми **Восстановить**. Перед сменой активного профиля восстанови исходное состояние.

Библиотека поддерживает поиск, фильтры по типу, избранное, переименование, копирование, удаление и экспорт. Очередь можно сортировать вручную, сохранять и загружать как профиль или экспортировать одним ZIP. Проверка активной установки различает применённые ресурсы, восстановленные файлы и конфликты с внешними изменениями.

В обычной установке менеджер работает с текущей папкой версии. Обновление Roblox может заменить эти файлы. Для Bloxstrap программа записывает ресурсы в папку `Modifications`. Старые резервные копии PlayerModLoader можно восстановить из новой версии. Версия Roblox из Microsoft Store не поддерживается.

## Свои моды

Импортируй ZIP или папку, сохраняя исходную структуру путей. Допускается одна общая внешняя папка в ZIP. Папки `content` и `PlatformContent` могут быть вместе в одном паке. ZIP до 16 МиБ. Программа принимает только следующие ресурсы.

| Ресурс | Поддерживаемые файлы |
| --- | --- |
| Курсоры клавиатуры и мыши | `content/textures/Cursors/KeyboardMouse/{ArrowCursor,ArrowFarCursor,IBeamCursor}.png` |
| Старые курсоры | `content/textures/{ArrowCursor,ArrowFarCursor}.png` |
| Индикатор фокуса и перетаскивания | `content/textures/Cursors/FocusLocation.png` и `content/textures/Cursors/DragDetector/{ActivatedCursor,HoverCursor}.png` |
| Курсоры геймпада | `content/textures/Cursors/Gamepad/{IBeamCursor,Pointer,Pointer@2x,PointerOver,PointerOver@2x}.png` |
| Небо | Все шесть `PlatformContent/pc/textures/sky/sky512_{bk,dn,ft,lf,rt,up}.tex` в DDS DXT1 1024×1024 с 11 mip-уровнями |
| Звуки | `content/sounds/{oof,ouch,volume_slider}.ogg` |

Курсоры в паке должны быть PNG до 128×128 и до 256 КиБ. Звуки должны быть Ogg Vorbis до 2 МиБ на файл. Названия в фигурных скобках обозначают отдельные имена. Конкретная игра должна использовать заменяемый локальный ресурс, чтобы эффект появился в ней. Игры с собственными текстурами неба используют их.

## Редактор и 202 настройки

Открой **Редактор ресурсов** или нажми **Редактировать копию** у мода в библиотеке. Выбери ресурс в верхнем списке и нажми **Загрузить ресурс**. Курсор можно сделать из PNG или JPEG, звук загрузить из Ogg Vorbis. Для неба нажми **Небо из 6 картинок** и выбери папку с квадратными PNG или JPEG размером от 64 до 4096 пикселей по стороне.

| Имя | Сторона |
| --- | --- |
| `bk` | Задняя |
| `dn` | Нижняя |
| `ft` | Передняя |
| `lf` | Левая |
| `rt` | Правая |
| `up` | Верхняя |

Есть 98 позиций для неба. По 14 параметров для всего неба и для каждой из шести сторон. Яркость, контраст, насыщенность, теплота, оттенок, гамма, тени, света, резкость, размытие, поворот, два зеркала и затемнение углов. Сначала применяются общие настройки, затем параметры конкретной стороны.

Есть ещё 104 позиции для курсоров. По восемь параметров для каждого из 13 ресурсов. Яркость, оттенок, поворот, два зеркала, непрозрачность, масштаб и обводка. Выбранную текстуру можно просмотреть, сбросить её параметры, сохранить результат новым модом или экспортировать ZIP.

## 10 предупреждений

1. За использование модифицированного Roblox Player аккаунт могут забанить.
2. Если Roblox расценит замену локального ресурса как модификацию клиента, аккаунт могут забанить.
3. Если античит распознает установку как изменённую, аккаунт могут забанить даже при косметических изменениях.
4. При нарушении правил Roblox сторонним ПО аккаунт могут забанить временно.
5. За повторное использование модифицированного клиента аккаунт могут забанить навсегда.
6. Изучай содержимое ZIP перед применением и скачивай пакеты из источников, которым доверяешь.
7. Перед применением или восстановлением полностью закрой Roblox Player и дождись завершения обновлений.
8. После обновления Roblox проверь совместимость пака с новой версией.
9. Сохраняй резервные копии менеджера в `%LOCALAPPDATA%\PlayerModLoader` до восстановления исходных файлов.
10. Ответственность за выбор пака, его применение и использование изменённых ресурсов лежит на пользователе.

## Сборка

На Windows с Python 3.11+ сначала установи зависимость командой `python -m pip install -r requirements.txt`, затем запусти `python app.py` для запуска из исходников. Для портативного EXE установи PyInstaller и выполни `python -m PyInstaller --onefile --windowed --name PlayerModLoader app.py`. Результат появится в `dist`.

`python -m unittest -v` проверяет операции на отдельной временной установке.

Чтобы собрать пример неба из исходников, запусти `python examples/make_aurora.py`.
